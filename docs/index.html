    What runs here

    Stateful in-memory fixture

    The page evaluates the cap, mutates a session-only cart map, reads an independent snapshot, and exposes pass, refusal, and idempotent states without a network request.

    What runs in the repo

    Stateful mock integration

    The Go integration test resolves candidates, builds outputs, mutates a local mock cart, reads it back, and verifies an idempotent second run.

    What this does not prove

    No live-account result

    The fixture is not a retailer session, customer outcome, production-scale test, or checkout. Product labels remain authoritative for allergies.

    Carrito is unofficial and is not affiliated with Alcampo or Auchan. The public demo uses sanitized mock data and makes no retailer request.
